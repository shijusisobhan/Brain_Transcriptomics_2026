# Brain_Transcriptomics_2026

This repository provides the code and analysis pipelines supporting the identification of candidate sleep homeostasis (“slee-per”) genes from multi-dataset transcriptomic analyses. It includes correlation analyses, heatmaps, PCA, behavioral data integration, and visualization workflows used in the study.

Reference: Clark Rosensweig, Aadish Shah, Shiju Sisobhan, Tomas Andreani, Elzbieta Kula-Eversole, and Ravi Allada (2026). Brain Transcriptomics Across Diverse Sleep-Wake Manipulations Reveals Multiple Homeostatic Pathways in Drosophila. (https://doi.org/10.64898/2026.02.28.708752)
